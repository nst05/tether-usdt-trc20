ХАРАКТЕРИСТИКИ
════════════════════════════════════════════════════════════════

CRC Алгоритм:
  • Тип: CRC-16 CCITT
  • Полином: 0x1021
  • Инициализация: 0xFFFF
  • Отражение: НЕТ
  • Final XOR: 0x0000

Формат Данных:
  • Представление: Fixed-Point (value × 100)
  • Порядок: Big-Endian
  • Размер значения: 4 байта
  • Размер CRC: 2 байта
  • Блок: 40 байт (значение + дубль + паддинг)
  • Структура: Блок (40) + CRC (2) = 42 байта

EEPROM:
  • Тип: 24C256 (2048 байт)
  • Блоков: 8 × 256 байт
  • Адреса: 0x50-0x57 (I2C)
  • Программатор: CH341 через i2cpy

ИСПОЛЬЗОВАНИЕ
════════════════════════════════════════════════════════════════

1. GUI (рекомендуется):
   python crc_storage_gui.py

2. Командная строка:
   python crc_storage_cli.py list file.bin
   python crc_storage_cli.py set file.bin 0x01C1 9442.36

3. Интерактивный режим:
   python crc_storage_interactive.py

4. Hex-дамп редактор:
   python crc_storage_dump.py edit file.bin
