                         🎯 ОСНОВНЫЕ ВОЗМОЖНОСТИ
════════════════════════════════════════════════════════════════════════════════

1. GUI ПРИЛОЖЕНИЕ
   • Три вкладки: Значения, Дамп, I2C/EEPROM
   • Редактирование с автоматическим пересчётом CRC
   • Тёмная тема GitHub
   • Резервное копирование (.bak файлы)

2. I2C/EEPROM ЗАПИСЬ
   • Три поля с auto-расчётом:
     - Поле 1: Значение (вводит пользователь)
     - Поле 2: HEX (автоматически)
     - Поле 3: CRC-16 (автоматически)
   • CH341 программатор поддерживается
   • 24C256 EEPROM (2048 байт)
   • Write & Verify цикл
   • Точечная запись: ровно 42 байта

3. CRC-16 CCITT
   • Polynomial: 0x1021
   • Init: 0xFFFF
   • No reflection
   • XOR out: 0x0000

4. ДАННЫЕ
   • Fixed-Point: value × 100
   • Big-Endian: 4 байта
   • Структура: 40 байт блок + 2 CRC = 42 байта

                         🚀 БЫСТРЫЙ СТАРТ
════════════════════════════════════════════════════════════════════════════════

1. Распаковать архив:
   tar -xzf crc_storage_tools_v2.2.tar.gz

2. Установить зависимости:
   pip install PyQt5
   pip install i2cpy  (для I2C/EEPROM)

3. Запустить GUI:
   python crc_storage_gui.py

4. Если проблемы:
   • Смотрите TROUBLESHOOTING_I2C.md
   • Проверьте debug логи в приложении
   • Используйте чек-лист для hardware

6. Следуйте рекомендациям
