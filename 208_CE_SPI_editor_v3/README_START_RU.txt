CE208 SPI EDITOR 3.1.0 — БЫСТРЫЙ СТАРТ

1. Запустите CE208_SPI_Editor_v3.exe.
2. Нажмите «Открыть дамп…» и выберите BIN.
   Оставьте «Процессор: Авто» для целого рабочего дампа. Если дамп пустой или
   повреждён и профиль не определяется, вручную выберите V8530, MSP4xx либо STM32.
3. На вкладке «Текущая энергия» введите T1–T8 группы 1 (1.8.x).
4. Чтобы отдельно изменить вторую группу, включите чекбокс
   «Редактировать вторую группу тарифов (2.8.x / 4.8.x)»
   и введите её T1–T8.
5. При включённой авто-реактивной программа рассчитывает пары:
   3.8.x = 1.8.x × K, 4.8.x = 2.8.x × K.
6. Нажмите «СОГЛАСОВАТЬ И ЗАПИСАТЬ» и сохраните новый BIN.

ВАЖНО
- Если чекбокс второй группы снят, банки 2.8/4.8 и их архивы не меняются.
- Действующий тариф Tn у прибора один общий для обеих групп.
- Редактирование полного SPI обновляет архивы; прямая запись CH341 обновляет только
  текущие записи 8-КБ памяти и никогда не трогает архивы SPI/журнал событий.
- Исходный дамп не перезаписывается автоматически: результат сохраняется в новый файл.
- Перед прошивкой сохраните резервную копию исходного BIN.
- Программа блокирует запись, если выбранный процессор противоречит CRC дампа.

Полное описание, CRC, карта банков и сборка из исходников: README_RU.md.
