# Клиент взаимодействия со стендом (RS-485)

Безопасный контур по разделу 27 технического отчёта: диагностическое чтение,
авторизация штатным паролем и чтение памяти. Команды записи (CMD 0x03/0x07)
намеренно не включены.

## Установка

```sh
pip install -r requirements.txt
```

## Запуск

```sh
python3 gui.py           # реальный COM-порт (RS-485 адаптер)
python3 gui.py --sim     # встроенный симулятор, без железа
```

## Состав

| Файл | Назначение |
|---|---|
| `stand.py` | транспортное ядро: кадры, CRC-16/MODBUS, команды чтения/авторизации |
| `gui.py` | настольный клиент (PyQt5): соединение, автопоиск, диагностика, лог кадров |
| `sim.py` | байтовый симулятор стенда для проверки GUI без железа (только чтение) |

## Возможности

- Подключение к COM-порту, выбор скорости (600–19200) и чётности; автопоиск.
- Диагностика (только чтение): тест связи, идентификация (SN + дата),
  базовая конфигурация, сетевой адрес, флаги состояния, мгновенные значения фаз.
- Авторизация штатным паролем (CMD 0x01, уровни 1/2), закрытие канала.
- Чтение памяти/таблиц (CMD 0x06), произвольная команда чтения.
- Живой лог кадров запрос/ответ в HEX с отметками времени.

Проверено против встроенного симулятора; кадры совпадают с эталонами прошивки.

## Сервисный слой

`service.py` — безопасная работа с сервисным уровнем прибора: определение
сервиса, резервные копии, верифицированная запись, журнал кадров, восстановление.
Подробное руководство — `../docs/SERVICE_CLIENT.md`. Демонстрация порядка работы
без железа: `python3 service.py --sim`.

Сервисный уровень включается только аппаратно (вход P2.5); программа его не
открывает. Подмены показаний и регулировки скорости счёта в модуле нет.
