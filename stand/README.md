# Разбор стенда на MSP430

Трёхфазный счётчик электроэнергии на MSP430F2xx. Обмен с ПК — по RS-485
(канал USCI_A1, P3.6/P3.7, управление направлением DE на P2.2), протокол
с кадрами `[адрес][команда][аргументы][CRC-16/MODBUS]`.

## Документация

| Файл | Содержание |
|---|---|
| `docs/PROTOCOL.md` | **спецификация протокола** (платформа, физика, кадр, CRC, команды) |
| `docs/COMMANDS.md` | **полный справочник всех 9 команд и 85 подкоманд** (сигнатуры, поля запроса/ответа) |
| `docs/BUTTONS.md` | **разбор двух кнопок** (P1.5/P1.6): опрос, антидребезг, текущие функции, точки врезки |
| `docs/MEMORY.md` | карта ключевых переменных RAM/INFO |

## Данные и артефакты

| Файл | Содержание |
|---|---|
| `firmware.hex` | исходный образ Intel HEX |
| `dis.txt` | дизассемблированный листинг (покрытие 90 %) |
| `meta.json` | функции, таблицы переходов, карта глобальных переменных RAM |
| `cmdmap.json` | машиночитаемая карта команд (для GUI) |
| `host/stand.py` | транспортное ядро обмена (кадры, CRC-16/MODBUS, базовые команды) |

## Инструменты

| Файл | Содержание |
|---|---|
| `tools/msp430dis.py` | дизассемблер MSP430 |
| `tools/analyze.py` | рекурсивный обход от векторов + раскрытие таблиц переходов |
| `tools/hex2bin.py` | Intel HEX → плоский образ `fw.bin` |
| `tools/build_cmdmap.py` | извлечение сигнатур обработчиков → `cmdmap.json` |
| `tools/handler_summary.py` | текстовая сводка обработчиков |
| `tools/gen_commands_md.py` | генерация `docs/COMMANDS.md` из карты |

## Воспроизведение

```sh
cd stand/tools
python3 hex2bin.py        # firmware.hex -> fw.bin
python3 analyze.py        # -> dis.txt, meta.json
python3 build_cmdmap.py   # -> cmdmap.json
python3 gen_commands_md.py # -> ../docs/COMMANDS.md
```
