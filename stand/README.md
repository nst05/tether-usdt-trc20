# Разбор стенда на MSP430

| Файл | Содержание |
|---|---|
| `firmware.hex` | исходный образ Intel HEX |
| `docs/PROTOCOL.md` | **спецификация протокола**, восстановленная по коду |
| `dis.txt` | дизассемблированный листинг (покрытие 85 %) |
| `meta.json` | функции, таблицы переходов, карта глобальных переменных RAM |
| `tools/msp430dis.py` | дизассемблер MSP430 |
| `tools/analyze.py` | рекурсивный обход от векторов + раскрытие таблиц переходов |
| `docs/BUTTONS.md` | **разбор двух кнопок** (P1.5/P1.6): опрос, антидребезг, текущие функции, точки врезки |
| `host/stand.py` | транспортное ядро обмена (кадры, CRC-16/MODBUS, базовые команды) |

Воспроизвести листинг:

```sh
cd stand/tools && python3 analyze.py     # ожидает fw.bin рядом
```
