# Две кнопки стенда — разбор по коду

Всё выведено из прошивки; адреса позволяют перепроверить в `stand/dis.txt`
(участок опроса лежал в «дыре» обхода — восстановлен прямым дизассемблированием
0x3384–0x3454 и 0x E434–0x E522).

## Подключение

| Кнопка | Пин | Маска | Конфигурация |
|---|---|---|---|
| **Кнопка 1** | **P1.6** | 0x40 | вход, активный низкий |
| **Кнопка 2** | **P1.5** | 0x20 | вход, активный низкий |

Пины переведены во вход в reset-инициализации: `bic.b #0x7d, &P1DIR` (0x1268),
`P1SEL` очищен (0x124E) — это GPIO без периферийной функции. Подтяжка внешняя
(регистры `PxREN` в прошивке не настраиваются). «Нажата» = замыкание пина на землю.

## Опрос и антидребезг (0x3384–0x3454)

Процедура вызывается периодически (делитель на счётчиках 0x02AD/0x02AE).
Каждая кнопка читается **три раза подряд**; чтобы засчитать нажатие, все три
чтения должны показать низкий уровень:

```
33C8  bit.b #0x40,&P1IN ; jc release   \
33D0  bit.b #0x40,&P1IN ; jc release    > Кнопка 1 (P1.6)
33D8  bit.b #0x40,&P1IN ; jc release   /
33E0  inc.b &0x032D                     ; счётчик удержания++
```

Пока кнопка удерживается — растёт счётчик удержания (0x032D для К1, 0x032E для К2).
В момент **отпускания** формируется событие в байте флагов **0x032C**:

| Бит 0x032C | Смысл |
|---|---|
| 0 | Кнопка 1 была нажата (событие) |
| 1 | …нажатие короткое (удержание < 0x19 = 25 сканов) |
| 2 | Кнопка 2 была нажата (событие) |
| 3 | …нажатие короткое |

То есть прошивка уже различает **короткое и длинное** нажатие каждой кнопки.

## Текущие функции кнопок (диспетчер 0xE434–0xE522)

Диспетчер читает 0x032C и правит слово состояния интерфейса **0x039F (UI_flags)**,
которое управляет автоматом ЖК-дисплея (рендер 0x6F00–0x7FF0).

**Кнопка 2 (P1.5)** — навигация по индикатору:
* короткое нажатие (0xE50A): `mov.b &0x083D,r13; call 0x7EE0; mov.b r13,&0x083D`
  — **листание страниц индикации** (0x083D — индекс текущего экрана);
* длинное (0xE51E): `bis.b #4,&UI` — вход в режим/подтверждение.

**Кнопка 1 (P1.6)** — вход/подтверждение в меню:
* короткое в режиме 8 (0xE448–0xE4D8): переключает и пересчитывает
  контрольную сумму блока 0x0500–0x0508 (подтверждение значения/калибровки);
* иначе/длинное (0xE4DE/0xE4EE): выход или переход по меню
  (`bic.b #0x41,&UI`, `bis.b #4,&UI`, вызов рендера 0x7EE0).

## Куда встраивать новые функции

Точка врезки — **диспетчер 0xE434–0xE522**: сюда приходят готовые,
уже отдебаунсенные события (0x032C бит0/2 — факт нажатия, бит1/3 — короткое/длинное).
Новую реакцию на кнопку можно повесить:

* на **длинное нажатие** любой из кнопок (сейчас длинные ветки короткие — есть место);
* на **комбинацию** К1+К2 (обе одновременно уже частично детектируются на 0x343E–0x3450,
  результат — 0x039F бит3);
* на **новый режим индикации** (добавить страницу в автомат 0x083D/UI_flags).

Свободного флеша под обработчик и таблицу — см. будущий отчёт по карте
свободных областей; хвост 0xFFC0–0xFFDF залит 0xFF.

Что именно должны делать кнопки — единственное, чего в коде нет; это и есть
спецификация, которую нужно задать.
