# Модель доступа стенда

Восстановлено по прошивке; адреса — для перепроверки в `dis.txt`.

## Три уровня

| Уровень | Как включается | Хранение | Признак в прошивке |
|---|---|---|---|
| **1** | пароль по сети, команда `01 01 [пароль6]` | внешняя память 0x004F (резерв 0x014F) | `0x06B3 |= 0x01` |
| **2** | пароль по сети, команда `01 02 [пароль6]` | внешняя память 0x0048 (резерв 0x0148) | `0x06B3 |= 0x02` |
| **сервис (3)** | **аппаратно** — вход **P2.5** на землю, либо внутренний флаг 0x04F2.12 | — | `0x08B8.8 → 0x06B3 |= 0x04` |

Пароль — 6 байт; седьмой байт записи — контроль `XOR` от 0xF0 (не хэш).
Основная и резервная копии зеркальны со сдвигом 0x0100.

## Почему на 3-й уровень нельзя «войти» командой

Сетевого пароля для сервисного уровня **нет**. Он выдаётся аппаратно и
**пересчитывается на каждый принятый кадр**:

```
; sub_49AA — опрос сервисного входа, вызывается из главного цикла (0x203E)
49AE  bit.b #0x20, &P2IN      ; вход P2.5
49B4  jz    0x49C6            ; P2.5 == 0 (на землю)   → сервис ВКЛ
49B6  bit   #0x1000, &0x04F2  ; либо внутренний флаг 0x04F2.12
49BC  jc    0x49C6            ;                        → сервис ВКЛ
49BE  bic   #0x100, &0x08B8   ; иначе сервис ВЫКЛ
49C6  bis   #0x100, &0x08B8   ; сервис ВКЛ: 0x08B8.8 = 1

; разбор кадра — перенос признака в маску доступа команды (0x8328)
8328  bit   #0x100, &0x08B8
8330  bis.b #4, &0x06B3       ; сервис активен → бит 0x04
8336  bic.b #4, &0x06B3       ; иначе снять
```

- **P2.5** — дискретный вход (`bic.b #0x60,&P2DIR`, 0x1294). Это сервисный
  контакт/джампер; точную точку на плате даёт только схема. По смыслу — контакт,
  доступный после вскрытия пломбы: в этом и есть физическая защита уровня.
- **0x04F2.12** — альтернатива: флаг взводится один раз при старте (0x14F4),
  если проверка блока внешней памяти (копия в RAM 0x04C0, 4 слова) дала ненулевой
  результат. То есть сервис может быть «зашит» хранимым признаком без P2.5.

## Как признак доступа проверяют команды

`0x06B3` — маска доступа текущего кадра: бит0 — уровень 1, бит1 — уровень 2,
бит2 — сервис. Она формируется заново на каждый кадр (пароли — через CMD 01,
сервис — из 0x08B8.8). Сервисные подкоманды дополнительно проверяют 0x08B8.8
напрямую (например, CMD 03 `0A`, CMD 07 mode 1 — 0xAB3A).

Коды ошибок доступа: `01` — неверная команда/параметр, `03` — недостаточный
уровень (0xB84E).

## Что видно снаружи, а что нет

- **Уровень пароля (1/2)** — наблюдаем: успех/ошибка команды `01`.
- **Статус-слово** — читается командой `08 09` (0x04F4/0x04F5 + 0x0839).
  Бит `0x0400` (0x04F4.10) — «активный режим».
- **Сервисный уровень (3)** — по шине **напрямую не читается**: 0x08B8.8 никогда
  не попадает в ответ. Единственный внешний признак — сервисные команды перестают
  возвращать ошибку доступа. Основной индикатор сервиса — это состояние входа P2.5,
  то есть аппаратное.

## Практическая проверка на стенде

1. Уровни 1/2: команда `01 01 [пароль]` / `01 02 [пароль]` → ответ-квитанция `00`.
2. Сервис: замкнуть контакт P2.5 на землю (или иметь прибор с флагом 0x04F2.12).
   Признак — сервисные операции начинают отвечать данными/`00` вместо ошибки.
