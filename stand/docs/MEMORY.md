# Карта памяти — ключевые переменные

Восстановлено по обращениям в дизассемблированной прошивке. Полный
частотный список — в `meta.json` (ключ `ram`). Здесь — осмысленные области.

## INFO-память (0x1000–0x10FF, энергонезависимая)

| Адрес | Содержание |
|---|---|
| 0x1000–0x103F | INFO_D — калибровочные/заводские коэффициенты |
| 0x1040–0x107F | INFO_C — калибровочные коэффициенты |
| 0x1080 | серийный номер (4 байта) + дата выпуска (3 байта) |
| 0x1080–0x10BF | INFO_B — параметры экземпляра |
| 0x10C0–0x10FF | INFO_A |

## Буферы каналов связи (RAM)

| Адрес | Назначение |
|---|---|
| 0x04B0–0x04C7 | буфер кадра канала A1 (RS-485), 24 байта |
| 0x0810–0x0827 | буфер кадра канала A0, 24 байта |
| 0x04A4 / 0x0828 | указатель приёма A1 / A0 |
| 0x04A6 / 0x082A | счётчик принятых байт A1 / A0 |
| 0x04A7 / 0x082B | флаги состояния канала A1 / A0 |
| 0x05AC / 0x0836 | указатель передачи A1 / A0 (пинг-понг 0x4B0/0x4C0) |
| 0x06B0–0x06B6 | рабочая область обработки кадра (frame_ptr) |
| 0x0680 | внутренний служебный кадр |

## Параметры узла и связи

| Адрес | Назначение |
|---|---|
| 0x04FE | сетевой адрес узла (NET_ADDR) |
| 0x04E1 | адрес/номер второго канала |
| 0x04E0 | байт конфигурации UART (скорость 3:0, чётность 5:4, режим бит7) |
| 0x04E2 | индекс скорости |
| 0x04FD | индекс активного канала |
| 0x07DF | текущая подкоманда (+ бит6 для CMD3, бит7 для CMD7) |
| 0x06B3 | флаги формируемого ответа |

## Права доступа / пароли

| Адрес | Назначение |
|---|---|
| 0x0500–0x0507 | пароль/значение (уровень 1) |
| 0x0508 | XOR-контрольная сумма блока 0x0500 |
| 0x050C–0x050E | флаги режима доступа |

## Метрология (трёхфазный счётчик)

| Адрес | Назначение |
|---|---|
| 0x0300 / 0x0302 | накопитель энергии, младшее слово (LL/LH) |
| 0x0308 / 0x030A | накопитель энергии, старшее слово (HL/HH) |
| 0x0306 | делитель импульсов энергии |
| 0x0368 / 0x0369 | импульсные счётчики |
| 0x03E8 / 0x03F8 / 0x0408 | мгновенные значения фаз A / B / C (2 байта BE) |
| 0x0316 / 0x043C | пороги/уставки сравнения |
| 0x0630–0x0644 | сдвиговые регистры выборки сигнала (программный тракт) |

## Служебные флаги состояния

| Адрес | Назначение |
|---|---|
| 0x04F0 / 0x04F2 / 0x04F4 / 0x04F6 / 0x04F8 / 0x04FA | слова флагов режимов/событий (наиболее используемые) |
| 0x066C | флаги подсистемы измерения/связи |
| 0x027C / 0x028C / 0x029C | флаги трёх тарифных/фазных каналов |

## Интерфейс оператора

| Адрес | Назначение |
|---|---|
| 0x032C | события кнопок (бит0/2 — нажата К1/К2, бит1/3 — короткое) |
| 0x032D / 0x032E | счётчики удержания кнопок К1 / К2 |
| 0x039F | слово состояния UI (автомат ЖК-индикатора) |
| 0x083D | индекс текущей страницы индикатора |
| 0x048E / 0x047E | буфер/сегменты ЖК-индикатора |
