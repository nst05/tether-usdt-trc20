# Полный справочник команд стенда

Сгенерировано автоматически из дизассемблированной прошивки (`tools/build_cmdmap.py` → `cmdmap.json`). Сигнатуры (длина, поля запроса/ответа, затронутые ячейки) извлечены анализом потока управления каждого обработчика; пояснения — по ручному разбору.

Формат кадра: `[ADDR][CMD][подкоманда/аргументы][CRC_lo][CRC_hi]`, CRC-16/MODBUS. Подробности — в `PROTOCOL.md`.

**Обозначения:** `len` — допустимая полная длина кадра (проверка `cmp #N,r8`); `req` — смещения байтов-аргументов в запросе; `resp` — число байт данных в ответе; `данные` — характерные ячейки RAM/INFO, которые обработчик читает(r)/пишет(w).

## CMD 0x00 — тест связи

*Обработчик 0x8498. len=[#4], req=—.*

Проверка связи. Запрос 2 байта данных (адрес+код) + CRC = 4. Ответ — квитанция.

## CMD 0x01 — открыть канал

*Обработчик 0x84F4. len=[#11], req=[#2].*

Открытие канала связи. Байт 2 — уровень доступа (1 или 2), байты 3..8 — пароль (6). Длина 11.

## CMD 0x02 — закрыть канал

*Обработчик 0x8590. len=[#4], req=—.*

Закрытие канала. Сбрасывает права доступа. Длина 4.

## CMD 0x04 — запись расширенная

*Обработчик 0xA0FE. len=[#5, #6], req=[#2, #3].*

Запись расширенная (калибровка/режимы). Байт 2 — подкоманда, байт 3 — параметр.
