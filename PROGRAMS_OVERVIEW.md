# CRC Storage Programs — Обзор и использование

## Созданные программы

### 1. **crc_storage_gui.py** ⭐ (рекомендуется)
Полнофункциональное графическое приложение для редактирования.

**Возможности:**
- ✓ Загрузка и просмотр файлов
- ✓ Таблица со всеми значениями и CRC
- ✓ Редактирование значений с автоматическим пересчётом CRC
- ✓ Сохранение с автоматической резервной копией
- ✓ Загрузка последнего открытого файла
- ✓ Тёмная тема (GitHub Dark)
- ✓ Валидация всех данных

**Запуск:**
```bash
python crc_storage_gui.py
```

**Сборка в exe:**
```bash
pyinstaller --onefile --windowed crc_storage_gui.py
```

---

### 2. **crc_storage_cli.py** 💻
Утилита командной строки для быстрых операций.

**Команды:**
```bash
# Показать все значения
python crc_storage_cli.py list file.bin

# Читать значение
python crc_storage_cli.py get file.bin 0x01C1

# Записать значение
python crc_storage_cli.py set file.bin 0x01C1 9999.99

# Справка
python crc_storage_cli.py info
```

**Примеры:**
```bash
# Вывести все значения с их CRC
python crc_storage_cli.py list data.bin

# Прочитать значение на позиции 0x200
python crc_storage_cli.py get data.bin 0x200

# Изменить значение на позиции 0x100
python crc_storage_cli.py set data.bin 0x100 1234.56
```

### 3. **crc_storage_surgical.py** 🔬
Демонстрация точечного редактирования (только нужные данные).

**Особенности:**
- ✓ Точное изменение ТОЛЬКО 42 байта (40 блок + 2 CRC)
- ✓ Другие данные файла не трогаются
- ✓ Логирование всех изменений
- ✓ Проверка целостности

**Примеры:**
```bash
# Демонстрация принципа редактирования
python crc_storage_surgical.py --example demo

# Пример изменения одного значения
python crc_storage_surgical.py --example single

# Пример изменения нескольких значений
python crc_storage_surgical.py --example multiple
```

## Алгоритм CRC-16 CCITT

```
Полином:        0x1021
Инициализация:  0xFFFF
Отражение вх:   НЕТ
Отражение вых:  НЕТ
Final XOR:      0x0000
```

## Представление данных

```
Формат:   Fixed-Point (value × 100)
Порядок:  Big-Endian
Размер:   4 байта (32-бит)
Диапазон: 0.00 – 42949672.95
```

## Структура блока (40 байт)

```
Позиция  Размер  Содержимое
────────────────────────────────────────
0x00     4 byte  Значение (big-endian)
0x04     4 byte  Дубль значения
0x08     32 byte Паддинг нулями
────────────────────────────────────────
Total:   40 byte
```

## CRC хранение

```
Позиция: После 40-байтового блока
Размер:  2 байта (16-бит, big-endian)
```

## Примеры значений

| Значение | Целое | HEX        | CRC-16 |
|----------|-------|------------|--------|
| 9442.36  | 944236| 0x000E686C | 0xAC55 |
| 9440.38  | 944038| 0x000E67A6 | 0x8748 |
| 12.34    | 1234  | 0x000004D2 | 0xC7D9 |
| 50.00    | 5000  | 0x00001388 | 0x3798 |

## Использование в Python

### Вычисление CRC
```python
from crc_storage_cli import make_block, crc16_ccitt

value = 9442.36
block, crc = make_block(value)
print(f"Значение: {value} → CRC: 0x{crc:04X}")
```

### Работа с файлом
```python
from crc_storage_cli import StorageFile

# Загружаем
storage = StorageFile('data.bin')
storage.load()

# Показываем значения
for item in storage.values:
    print(f"0x{item['pos']:06X}: {item['value']:.2f}")

# Меняем значение
storage.write_value(0x01C1, 1234.56)

# Сохраняем
storage.save()
```
