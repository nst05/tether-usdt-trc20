# PIC16LF1934 Firmware Reading Guide

## Скрипты для считывания прошивки

### 1. **Python скрипт** (рекомендуется)
```bash
python3 pic_read.py
```
- Интерактивное меню
- Проверка подключения
- Попытка чтения прошивки
- Чтение конфигурации
- Безопасное стирание с подтверждением

### 2. **Bash скрипт**
```bash
chmod +x pic_read.sh
./pic_read.sh
```
- Быстрое выполнение
- Подходит для Linux/Mac
- Конвертация в бинарный формат

---

## ⚠️ Проблема с защитой

**Если установлен CODE_PROTECT бит:**
- Считывание памяти программ **БЛОКИРОВАНО**
- Чтение вернет нули или ошибку
- Это сделано специально в микроконтроллере

**Единственное решение:**
1. Стирать микроконтроллер (Erase) - сотрет защиту
2. Потом перепрограммировать

## Команды pk2cmd вручную

Если скрипты не работают, используйте напрямую:

### Проверка подключения
```bash
pk2cmd -P PIC16LF1934 -I
```

### Считывание прошивки
```bash
pk2cmd -P PIC16LF1934 -R -O firmware.hex
```
- `-R` = Read
- `-O файл` = Output file

### Считывание конфигурации
```bash
pk2cmd -P PIC16LF1934 -RC
```

### Стирание (сотрет защиту)
```bash
pk2cmd -P PIC16LF1934 -E
```

### Проверка ID микроконтроллера
```bash
pk2cmd -P PIC16LF1934 -ID
```

## Установка необходимых инструментов

### Windows
1. Установите **MPLAB X IDE**: https://www.microchip.com/mplab/mplab-x-ide
2. Установите **pk2cmd** отдельно: https://www.microchip.com/development-tools/

Затем добавьте путь в PATH:
```
C:\Program Files (x86)\Microchip\MPLAB X IDE\mplab_ipe\pk2cmd
```

### Linux (Ubuntu/Debian)
```bash
# Если есть пакет
sudo apt-get install pk2cmd

# Или установить вручную
# Скачайте с microchip.com и распакуйте
```

### Mac
```bash
brew install microchip-technology/tools/pk2cmd
```

## Альтернативные способы

### MPLAB X IDE (Графический интерфейс)
1. Откройте MPLAB X IDE
2. Tools → Embedded → PICkit 3 Programmer
3. Device → PIC16LF1934
4. Read → сохранить прошивку

### Python с pyusb (для прямого доступа)
```python
import usb.core

# Поиск Pickit
dev = usb.core.find(idVendor=0x04d8, idProduct=0x0033)
if dev:
    print("Pickit найден")
    # Дальше нужно реализовать протокол pk2
```

## Проверка результата

После успешного чтения:

```bash
# Проверить размер файла
ls -la firmware.hex

# Просмотреть содержимое
head -20 firmware.hex

# Конвертировать в бинарный формат
objcopy -I ihex -O binary firmware.hex firmware.bin

# Проверить размер бинарика
hexdump -C firmware.bin | head
```

Файл должен содержать данные, а не только нули (если не установлена защита).

## Если ничего не помогает

### Вариант 1: Стирание и перепрограммирование
```bash
pk2cmd -P PIC16LF1934 -E           # Стирание (сотрет защиту)
pk2cmd -P PIC16LF1934 -M -F новый_код.hex  # Программирование
```

### Вариант 2: Проверить подключение
- Убедитесь, что Pickit правильно подключен
- Проверьте питание микроконтроллера (обычно 5V или 3.3V)
- Посмотрите светодиоды на Pickit (должны гореть)

### Вариант 3: Использовать другой программатор
- MPLAB ICD3/ICD4 - официальные Microchip
- PicKit2/3/4 - по возрастанию функциональности

## Важно!

⚠️ **CODE_PROTECT = ON** → Считывание **НЕВОЗМОЖНО**

Это защита на уровне аппаратного обеспечения. Обойти её можно только:
1. **Стиранием** (сотрет код + защиту)
2. **Физическим анализом** (дорого, разрушает микросхему)
3. **Коммерческими сервисами** ("взлом" микроконтроллера)

Если это ваш микроконтроллер - используйте вариант 1 (стирание).
