# MT Writer — 200_MT и 310_MT в одной программе

Объединение двух прежних программ (`200_MT.py` и `310_MT.py`) в одно окно
с двумя вкладками. Логика записи в EEPROM 24C16 через CH341 не изменилась.

Что добавлено:

* **две вкладки** — `200_MT` и `310_MT`, каждая работает как раньше;
* **счётчик прошивок в каждой вкладке отдельно** — не сбрасывается при
  перезапуске программы и перезагрузке компьютера;
* **привязка к компьютеру** — одна копия работает на одном ПК.

## Файлы

| Файл             | Назначение                                             |
|------------------|--------------------------------------------------------|
| `mt_writer.py`   | сама программа (вкладки, запись в EEPROM, счётчики)     |
| `mt_license.py`  | код компьютера, ключи активации, проверка лицензии      |
| `mt_counters.py` | счётчики прошивок                                       |
| `mt_storage.py`  | где хранятся `license.key` и `counters.json`            |
| `keygen_mt.py`   | генератор ключей — **только для вас, клиенту не давать** |
| `mt_writer.spec` | сборка в один `.exe` через PyInstaller                  |

## Запуск из исходников

```bash
pip install -r requirements.txt
python mt_writer.py
```

## Сборка .exe

Проще всего — запустить `build_all.bat` (соберёт оба exe сразу).

Вручную:

```bat
python -m pip install -r requirements.txt pyinstaller
python -m PyInstaller mt_writer.spec     ->  dist\MT_Writer.exe
python -m PyInstaller keygen_mt.spec     ->  dist\keygen_mt.exe
```

Собираются **только два** файла:

| Файл                 | Кому                                              |
|----------------------|---------------------------------------------------|
| `dist\MT_Writer.exe` | клиенту — сама программа                          |
| `dist\keygen_mt.exe` | только вам — генератор ключей                     |

Остальные модули (`mt_license.py`, `mt_counters.py`, `mt_storage.py`)
отдельно компилировать не нужно: PyInstaller уже упаковал их внутрь
`MT_Writer.exe`. Клиенту достаточно одного файла `MT_Writer.exe` —
ни Python, ни исходников на его компьютере не требуется.

Если команда `pyinstaller` не находится (Python из Microsoft Store ставит
её в папку, которой нет в PATH), запускайте через `python -m PyInstaller`,
как показано выше. Если сборка ругается на `WindowsApps` — поставьте
обычный Python с python.org, Store-версия для PyInstaller не годится.

### Драйвер программатора — DLL CH341

Работает точно так же, как исходные 200_MT/310_MT: программа грузит
i2cpy, а тот берёт DLL драйвера CH341 из системы. Отдельной обработки в
коде нет — как в оригинале.

Чтобы запись шла, на компьютере должны быть:
- **USB-драйвер CH341** (`CH341SER.EXE`) — ставится один раз, в диспетчере
  устройств виден как `USB-EPP/I2C CH341A`;
- **DLL драйвера** (`CH341DLL.DLL` / `CH341DLLA64.DLL`) — её ставит пакет
  **CH341PAR** (сайт wch-ic.com) в систему. Как вариант — положить DLL
  рядом с `MT_Writer.exe`.

**Разрядность DLL должна совпадать с разрядностью exe.** Если собираете
64-битным Python — нужна 64-битная `CH341DLLA64.DLL`; 32-битная `CH341A.DLL`
рядом с 64-битным exe даст ошибку **«Bad Image» / `0xC000012F`**.

Если хотите вложить DLL прямо в exe (чтобы у клиента не ставить CH341PAR) —
положите файл `CH341*.DLL` **нужной разрядности** в папку `mt_writer`
рядом со spec: при сборке он упакуется (в консоли появится
`[spec] упакованы DLL драйвера: ...`). По умолчанию ничего не упаковывается.

`keygen_mt.exe` можно запускать и двойным кликом: он спросит код
компьютера и срок в диалоге. Из командной строки работают те же ключи,
что и у `keygen_mt.py`.

## Счётчики прошивок

* Счётчик у каждой вкладки свой: запись в `200_MT` не влияет на `310_MT`.
* Увеличивается **только после успешной записи и проверки чтением**.
  Ошибка связи, обрыв или неудачная проверка счётчик не двигают.
* Хранится в `counters.json` рядом с программой, вместе с датой и
  значением последней записи. Файл пишется атомарно, поэтому не бьётся
  при выключении питания.
* Файл подписан контрольной суммой: если счётчики правили вручную,
  программа покажет «⚠ файл счётчиков был изменён вручную».
* Сброса счётчика в интерфейсе нет специально. Обнулить можно только
  удалив `counters.json`.

Где лежат данные, видно внизу окна. По умолчанию — папка с программой,
а если она только для чтения (например, `C:\Program Files`), то
`%APPDATA%\MT_Writer`.

## Привязка к компьютеру

При первом запуске программа показывает окно активации с **кодом
компьютера** вида `B15C0-434B2-B000A-6E8A7`. Клиент присылает код вам,
вы генерируете ключ:

```bash
python keygen_mt.py B15C0-434B2-B000A-6E8A7            # бессрочно
python keygen_mt.py B15C0-434B2-B000A-6E8A7 --days 365 # на год
python keygen_mt.py --my-code                          # код текущего ПК
python keygen_mt.py --check КЛЮЧ --code КОД            # проверить ключ
```

Ключ (например `AEEYW4A-SOU4GA3-GBLV664`) клиент вводит в окне активации.
Он сохраняется в `license.key` и больше не запрашивается.

Проверка выполняется при запуске **и перед каждой записью** в EEPROM,
плюс раз в час, если программа не закрывается сутками. Срок лицензии
и код ПК всегда видны в строке внизу окна.

Что даёт защита:

* `license.key`, скопированный на другой компьютер, не работает —
  подпись привязана к коду того ПК, для которого выпущен ключ;
* дата последнего запуска пишется с контрольной суммой, поэтому перевод
  системных часов назад больше чем на 2 дня блокирует программу;
* без действующей лицензии кнопка «ЗАПИСАТЬ И ПРОВЕРИТЬ» выдаёт отказ.

Код компьютера **не меняется** при замене диска, ОЗУ или видеокарты и при
переустановке самой программы. Он **изменится** при переустановке Windows
(новый MachineGuid) — тогда нужен новый ключ.

## ОБЯЗАТЕЛЬНО перед распространением: смените секрет

Ключи подписываются HMAC-SHA256 с общим секретом. По умолчанию он открыто
лежит в `mt_license.py`:

```python
DEFAULT_SECRET = 'mt-writer-license-secret-change-me-2024'
```

Замените строку на свою (длинную, случайную) **до сборки .exe**. Тот же
секрет нужен генератору ключей — либо он читает его из файла, либо
задайте переменную окружения:

```bash
set MT_LICENSE_SECRET=ваш-секрет
python keygen_mt.py B15C0-434B2-B000A-6E8A7
```

Если секреты в сборке и в генераторе не совпадут — ключи не подойдут.

Честно о пределах защиты: секрет зашит в `.exe`, поэтому она рассчитана
на обычного пользователя, а не на реверс-инжиниринг. Для стойкости к
вскрытию нужна подпись Ed25519 (приватный ключ остаётся у вас, в
программе только публичный) — могу переделать, если понадобится.
