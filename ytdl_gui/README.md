# Загрузчик видео с YouTube (GUI)

Простая программа с графическим интерфейсом для скачивания видео и звука
с YouTube. Интерфейс — `tkinter` (входит в стандартную поставку Python),
загрузка — [yt-dlp](https://github.com/yt-dlp/yt-dlp).

## Возможности

- очередь ссылок: добавляйте сколько нужно, скачиваются последовательно;
- выбор качества: от 360p до 4K, «лучшее доступное», либо только звук (MP3 / M4A);
- скачивание целого плейлиста (файлы раскладываются в папку с его названием);
- субтитры, включая автоматические, для выбранных языков (по умолчанию `ru,en`);
- прогресс-бар с процентами, скоростью, объёмом и оставшимся временем;
- кнопка «Отмена» (или клавиша `Esc`) прерывает загрузку;
- журнал событий и ошибок прямо в окне;
- папка и настройки запоминаются в `~/.ytdl_gui.json`;
- докачка прерванных файлов при повторном запуске.

## Установка

Нужен Python 3.9 или новее. Ниже — команды для каждой системы; выполняйте
только строки для своей. Команды с `sudo apt` работают **лишь в Linux** — в
Windows их вводить не нужно, там нет ни `sudo`, ни `apt`.

### Windows

В командной строке, находясь в папке программы:

```bat
python -m pip install yt-dlp
```

tkinter в Windows уже входит в состав Python, отдельно ставить не надо.

Для склейки видео со звуком и конвертации в MP3 нужен **ffmpeg**:

```bat
winget install Gyan.FFmpeg
```

Либо скачайте вручную с https://ffmpeg.org/download.html и добавьте папку `bin`
в переменную `PATH`. После установки ffmpeg закройте и снова откройте
командную строку, иначе программа его не увидит.

### Linux (Ubuntu/Debian)

```bash
sudo apt install python3-tk ffmpeg
python3 -m pip install yt-dlp
```

Для Fedora — `sudo dnf install python3-tkinter ffmpeg`, для Arch —
`sudo pacman -S tk ffmpeg`.

### macOS

```bash
brew install python-tk ffmpeg
python3 -m pip install yt-dlp
```

### Если ffmpeg не установлен

Программа запустится и будет качать, но с ограничениями — при старте она
напишет об этом в журнале:

- берутся только готовые дорожки, где видео и звук уже в одном файле; YouTube
  отдаёт такие обычно не выше **720p**;
- выбор «Только звук» сохраняет исходную дорожку (`.m4a` или `.webm`) без
  конвертации в MP3.

Ограничение применяется автоматически: программа не запросит склейку, которую
не сможет выполнить. Высокое качество (1080p и выше) YouTube отдаёт видео и
звуком раздельно, поэтому для него ffmpeg обязателен.

Если чего-то не хватает, программа при запуске сама напишет, что именно
установить, вместо сообщения об ошибке Python.

### Предупреждение про JavaScript-движок

В журнале может появиться сообщение yt-dlp `No supported JavaScript runtime
could be found`. Скачиванию оно обычно не мешает, но часть форматов без
JS-движка бывает недоступна. Чтобы убрать его, установите Deno:
`winget install DenoLand.Deno` (Windows) или `brew install deno` (macOS);
yt-dlp найдёт его сам. Подробности — https://github.com/yt-dlp/yt-dlp/wiki/EJS

### Обновление yt-dlp

YouTube часто меняет внутренние API, и старые версии yt-dlp перестают
скачивать. Если появляются ошибки извлечения, первым делом обновитесь:

```bat
python -m pip install -U yt-dlp
```

## Запуск

```bash
python youtube_downloader.py
```

или

```bash
python -m ytdl_gui
```

## Как пользоваться

1. Вставьте ссылку в верхнее поле и нажмите **Добавить** (или `Enter`).
   В поле можно вставить сразу несколько ссылок через пробел.
2. Кнопка **Информация** покажет название, автора и длительность, ничего не скачивая.
3. Выберите папку и качество, при необходимости включите плейлист и субтитры.
4. Нажмите **Скачать**. Ход загрузки видно в прогресс-баре, подробности — в журнале.
5. Кнопка **Открыть** показывает папку с готовыми файлами в файловом менеджере.

## Структура

| Файл | Назначение |
| --- | --- |
| `youtube_downloader.py` | запуск программы из корня репозитория |
| `ytdl_gui/core.py` | загрузка и настройки yt-dlp, рабочий поток, без tkinter |
| `ytdl_gui/gui.py` | окно, виджеты, обработка событий |
| `ytdl_gui/startup.py` | проверка зависимостей с понятной подсказкой |
| `ytdl_gui/__main__.py` | точка входа для `python -m ytdl_gui` |

Рабочий поток не трогает виджеты напрямую: события складываются в
`queue.Queue`, а интерфейс разбирает её через `after()` — так tkinter не падает
из-за обращений из другого потока.

## Замечание

Скачивайте только то, на что у вас есть право: свои материалы, контент под
свободной лицензией или видео, где правообладатель разрешил загрузку. Массовое
копирование чужого контента нарушает условия использования YouTube.
