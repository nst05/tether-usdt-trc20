# Сборка integra101.exe под Windows

## Быстрый путь

1. Распакуйте архив в отдельную папку.
2. Положите туда `CH341DLLA64.dll` (для 64-битного Python) или `CH341DLL.dll`
   (для 32-битного). Файл идёт с драйверами программатора CH341 от WCH.
3. Запустите **`build_windows.bat`** двойным щелчком.

Готовый файл появится в `dist\integra101.exe`.

## Что делает .bat

| Шаг | Действие |
|---|---|
| 1 | Ищет Python (`py -3`, затем `python`), определяет разрядность |
| 2 | Проверяет, что все нужные файлы на месте |
| 3 | Ставит PyQt5, i2cpy, PyInstaller 6+ |
| 4 | Проверяет наличие DLL под вашу разрядность |
| 5 | Чистит прошлую сборку и компилирует по `crc_storage_writer.spec` |
| 6 | Проверяет, что exe создан, и печатает путь с размером |

На каждом шаге при ошибке сборка останавливается с внятным сообщением, а не
падает молча.

## Почему нужен .spec, а не голая команда

Обычная `pyinstaller crc_storage_gui.py` даёт exe, который **не сможет
писать в микросхему**. Две причины, обе закрыты в `crc_storage_writer.spec`:

### 1. Драйвер грузится динамически

i2cpy подбирает драйвер по строке:

```python
driver_module_name = "i2cpy.driver.{}".format(self.driver_name)
self.driver_module = import_module(driver_module_name)
```

Статический анализ такого не видит, модуль в сборку не попадает, и на
попытке открыть программатор вылетает `I2CInvalidDriverError`. Поэтому все
модули драйверов перечислены в `hiddenimports` явно.

### 2. DLL грузится по голому имени

```python
dll_name = "CH341DLLA64.dll" if sys.maxsize > 2147483647 else "CH341DLL.dll"
windll.LoadLibrary(dll_name)
```

Это происходит **прямо при импорте** драйвера. В onefile-сборке файлы
распаковываются во временную папку `sys._MEIPASS`, которой нет в путях
поиска DLL, — загрузка падает.

Решает runtime-хук `pyi_rth_ch341.py`: он выполняется до кода приложения,
находит DLL в `_MEIPASS` и подставляет переменную окружения `CH341DLL` с
полным путём. i2cpy читает её раньше, чем берёт имя по умолчанию:

```python
dll_name = os.getenv("CH341DLL")
```

Хук аккуратен: заданное вручную значение `CH341DLL` не перетирает, а если
DLL в сборку не клали — молча ничего не делает, и библиотека ищется рядом с
exe и в системе, как обычно.

## Если DLL нет на момент сборки

Сборка пройдёт, .bat об этом предупредит. Тогда положите `CH341DLLA64.dll`
рядом с готовым exe — этого достаточно.

## Ручная сборка

```cmd
pip install PyQt5 i2cpy "pyinstaller>=6.0"
pyinstaller --noconfirm --clean crc_storage_writer.spec
```

`spec` написан под PyInstaller 6+: в 5.x форма `EXE(...)` отличалась
(там был отдельный `a.zipfiles`).

## Проверка результата

Что должно быть внутри собранного exe:

- модули `i2cpy.driver.ch341`, `i2cpy.driver.ch341.dll`, `i2cpy.driver.ch347`
- модуль `crc_storage_i2c`
- runtime-хук `pyi_rth_ch341`
- сама `CH341DLLA64.dll`, если она была рядом при сборке

Сборка проверена на PyInstaller 6.22: все перечисленное попадает внутрь,
приложение стартует без ошибок импорта. Размер — около 48 МБ.

## Иконка и экран загрузки

Обе картинки генерируются кодом — бинарников в репозитории нет:

```cmd
python make_icon.py
```

Создаёт `icon.ico`, `icon.png` и `splash.png`. `build_windows.bat` вызывает
это сам, если файлов ещё нет.

### Почему .ico собирается вручную

Qt умеет писать ico, но кладёт туда одну картинку — Windows потом сам её
уменьшает, и на 16px выходит каша. Поэтому каждый из семи размеров
(16/24/32/48/64/128/256) рисуется отдельно, кодируется в PNG и укладывается
в контейнер ICO вручную. Мелкие размеры к тому же упрощены: на 24px у
микросхемы две толстые ножки вместо трёх тонких, на 16px их нет совсем —
остаётся чёткий силуэт.

### Две заставки, а не одна

| | Что закрывает | Чем нарисована |
|---|---|---|
| `splash.png` через `Splash()` | распаковку onefile, ещё до старта Python | tkinter, движком PyInstaller |
| `splash_screen.py` | инициализацию самого приложения | Qt, с анимацией |

Первая появляется мгновенно при запуске exe и держится, пока Python и Qt
грузятся. Вторая подхватывает эстафету и гасит первую вызовом
`pyi_splash.close()` — только когда ей уже есть что показать, иначе между
ними мигнул бы пустой экран.

**Заставке PyInstaller нужен tkinter.** Без него сборка обрывается с
ошибкой `Your platform does not support the splash screen feature`. На
Windows он идёт в комплекте с python.org, поэтому там всё работает; в spec
он специально НЕ внесён в `excludes`, хотя по весу просился бы. Если
tkinter всё же нет, spec это замечает и собирается без заставки.

### Анимация

Кольцо вокруг иконки заполняется по мере готовности, переливаясь из синего
в зелёный, поверх бежит блик, под иконкой дышит свечение. Показанный
прогресс догоняет заданный плавно, поэтому скачки вида «20% → 70%» не
дёргаются.

Инициализация занимает миллисекунды — быстрее, чем длится появление
панели. Без задержки экран мелькал бы почти невидимым, поэтому он держится
на виду минимум `MIN_VISIBLE_MS` (1.1 с) и только потом гаснет.

## Почему .bat написан транслитом

Первая версия была на кириллице с `chcp 65001` — и разваливалась:

```
'SING' is not recognized as an internal or external command
'onfirm' is not recognized as an internal or external command
'Порядок' is not recognized as an internal or external command
```

Причина: cmd читает .bat побайтово и запоминает позицию в файле. `chcp`
посреди исполнения меняет кодировку, позиция перестаёт совпадать с
границами символов, строки режутся прямо внутри буквы, а обрывки уходят
на исполнение как команды.

Поэтому файл теперь **чистый ASCII с CRLF**. Однобайтовая кодировка
рассинхронизироваться не может ни при какой кодовой странице консоли.

Кириллицу можно было бы вернуть, сохранив .bat в CP866 (тоже однобайтовая,
парсер не ломает) — но на англоязычной Windows она отобразилась бы
кракозябрами.

По той же причине `make_icon.py` печатает только ASCII: при
перенаправлении вывода Python берёт кодировку локали (cp437/cp1252), и
кириллица упала бы с `UnicodeEncodeError`.

## Как переименовать exe

Имя задаётся одной строкой в `crc_storage_writer.spec`:

```python
APP_NAME = "integra101"
```

`build_windows.bat` ищет результат по тому же имени — если меняете, поправьте
и в нём.

## Иконка

Положите `icon.ico` рядом со spec — она подхватится сама. Нет файла —
соберётся со стандартной иконкой.
