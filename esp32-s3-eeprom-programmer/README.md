# EEPROM-программатор на ESP32-S3-Touch-LCD-7

Порт настольной утилиты (PyQt5 + CH341, `all_tabs_ch341_merged_6tabs.py`) на
сенсорную плату **Waveshare ESP32-S3-Touch-LCD-7** (800×480, тач GT911).

Дисплей и тач подняты через официальную библиотеку **ESP32_Display_Panel**
(`esp_display_panel`) с пресетом платы Waveshare — драйверы RGB-панели, тача
GT911 и расширителя CH422G берутся из библиотеки, поэтому тач работает «из
коробки». EEPROM подключается к внешнему I²C-разъёму и обслуживается отдельным
I²C-контроллером.

## 6 программаторов (вкладки)

| Вкладка | Микросхема | Что делает |
|---------|------------|------------|
| 201     | 24C16      | Целая часть + случайная дробная, BCD + CRC16-IBM |
| c101    | 24C04      | Показание → кадры F8/FC, CRC8 (poly 0xB5) |
| 1F      | AT24C1024  | `round(value/2.56)`, CRC CCITT-FALSE, патч 0x0000..01FF |
| 3F      | AT24C1024  | `floor(value/2.56)`, + 0x9C по 0x1FB/0x1FF |
| 6803    | 24C04      | Кадры F8/FC + хвост `00 00 00 69` |
| 200_MT  | 24C16      | Значение (×100) по адресу 0x0040, LE |

Цикл: **считать → проверить → пропатчить → записать → считать обратно → сверить.**
Вся логика CRC/BCD/патчей **проверена побайтово** против оригинального Python.

## Подключение EEPROM

К внешнему I²C-разъёму платы (общая шина с тачем):

| Сигнал | GPIO | EEPROM |
|--------|------|--------|
| SDA    | 8    | SDA    |
| SCL    | 9    | SCL    |
| 3V3    | 3V3  | VCC    |
| GND    | GND  | GND / A0..A2 / WP |

Адреса EEPROM `0x50..0x57` не конфликтуют с тачем GT911. EEPROM работает на
втором I²C-контроллере (порт 1), тач — на своём; операции с памятью идут внутри
обработчика события LVGL, поэтому обе шины не активны на линиях одновременно.

## Вход по PIN и защита

- При старте — **экран входа по PIN** (пароль по умолчанию `1234`, задаётся
  `APP_DEFAULT_PASSWORD` в `app_config.h`). Клавиатура цифровая — PIN из цифр.
- **Смена PIN** прямо в интерфейсе: кнопка **Change PIN** в шапке (нужно ввести
  текущий и новый). PIN хранится в NVS и переживает перепрошивку данных.
- **Защита от перебора:** счётчик неверных попыток хранится в NVS (не сбрасывается
  перезагрузкой). При достижении лимита `APP_MAX_ATTEMPTS` (по умолчанию 5)
  **прошивка стирается** — плата уходит в ребут и не запустится, пока её не
  прошьют заново. Успешный вход сбрасывает счётчик.
- Кнопка **Lock** в шапке возвращает на экран входа.

> ⚠️ Осторожно с лимитом: после N неверных PIN устройство само себя «обнуляет».

## Сборка (Arduino IDE)

1. **Ядро:** *esp32* от Espressif (**Arduino-ESP32 v3.x**).
2. **Плата:** `ESP32S3 Dev Module`, обязательно **PSRAM: OPI PSRAM**,
   Flash 8/16 MB, USB CDC On Boot: Enabled.
3. **Библиотеки** (Library Manager):
   - **ESP32_Display_Panel** `1.0.x` (потянет зависимости: esp-lib-utils,
     ESP32_IO_Expander и др.);
   - **lvgl** `8.3.x`/`8.4.x`.
4. **lv_conf.h:** скопировать файл `lv_conf.h` из этой папки в каталог
   Arduino-библиотек **рядом с папкой `lvgl`** (уровнем выше её):
   ```
   Arduino/libraries/
   ├── lvgl/
   └── lv_conf.h   <- сюда
   ```
5. Открыть `esp32-s3-eeprom-programmer.ino` (все файлы папки собираются вместе),
   выбрать порт и прошить.

Пресет платы задаётся файлами `esp_panel_board_supported_conf.h`
(`BOARD_WAVESHARE_ESP32_S3_TOUCH_LCD_7`) и `esp_panel_drivers_conf.h` — они уже
в проекте, менять не нужно.

## Файлы проекта

| Файл | Назначение |
|------|------------|
| `esp32-s3-eeprom-programmer.ino` | точка входа: Board (дисплей/тач), I²C, UI |
| `simple_lvgl_port.*` | связка ESP32_Display_Panel ↔ LVGL (дисплей + тач) |
| `esp_panel_board_supported_conf.h` | выбор платы Waveshare |
| `esp_panel_drivers_conf.h` | включение драйверов |
| `lv_conf.h` | конфиг LVGL (копировать к библиотеке lvgl) |
| `eeprom_i2c.*` | I²C чтение/запись (24C16 / 24C04 / AT24C1024) |
| `meter_logic.*` | чистая логика CRC/BCD/патчей (тестируется на ПК) |
| `meters.*` | полный цикл прошивки каждого программатора |
| `ui.*` | тёмный интерфейс: вход по PIN + 6 вкладок + смена PIN |
| `security.*` | пароль в NVS, защита от перебора со стиранием прошивки |
| `app_config.h` | пины I²C EEPROM, заголовок, PIN и лимит попыток |
| `ui_font_18/24/34.c` | ASCII-шрифты LVGL |

## Примечания

- Слой дисплея/тача взят из проверенного на этой плате решения (библиотека
  ESP32_Display_Panel) — тач работает.
- Логика программаторов проверена побайтово против Python.
- Тексты интерфейса — латиницей (стандартные шрифты LVGL без кириллицы).
- При инверсии цветов — переключите `LV_COLOR_16_SWAP` в `lv_conf.h`.
