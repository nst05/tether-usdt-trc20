# EEPROM-программатор на ESP32-S3-Touch-LCD-7

Порт настольной утилиты (PyQt5 + CH341, `all_tabs_ch341_merged_6tabs.py`) на
автономную сенсорную плату **Waveshare ESP32-S3-Touch-LCD-7** (800×480, тач GT911).

Вместо ПК с USB-адаптером CH341 микросхемы EEPROM программируются прямо с платы:
свой встроенный I²C, сенсорный GUI на LVGL, вход по паролю.

## Что внутри (6 программаторов — вкладки)

| Вкладка   | Микросхема   | Что делает                                              |
|-----------|--------------|---------------------------------------------------------|
| 201       | 24C16        | Целая часть + случайная дробная, BCD + CRC16-IBM         |
| c101      | 24C04        | Показание → кадры F8/FC, CRC8 (poly 0xB5)                |
| 1F        | AT24C1024    | `round(value/2.56)`, CRC CCITT-FALSE, патч 0x0000..01FF  |
| 3F        | AT24C1024    | `floor(value/2.56)`, + 0x9C по 0x1FB/0x1FF               |
| 6803      | 24C04        | Кадры F8/FC + хвост `00 00 00 69`                        |
| 200_MT    | 24C16        | Значение (×100) по адресу 0x0040, LE                     |

Цикл на каждой вкладке тот же, что в оригинале:
**считать дамп → проверить → пропатчить → записать → считать обратно → сверить.**

Вся логика CRC/BCD/патчей перенесена 1:1 из Python и **проверена побайтово**
на ПК (совпадение с оригиналом для всех 6 программаторов).

## Подключение EEPROM

Программируемая микросхема вешается на тот же I²C-разъём платы, что и тач:

| Сигнал | GPIO ESP32-S3 | EEPROM (24Cxx / AT24C1024) |
|--------|---------------|----------------------------|
| SDA    | GPIO8         | SDA                        |
| SCL    | GPIO9         | SCL                        |
| 3V3    | 3V3           | VCC                        |
| GND    | GND           | GND / A0..A2 / WP          |

- Адреса EEPROM `0x50..0x57` не конфликтуют с тачем GT911 (`0x5D`) и
  расширителем CH422G — можно держать всё на одной шине.
- Подтяжки SDA/SCL на плате уже есть (для GT911), отдельные не нужны.
- Ножки A0..A2 микросхемы — на GND (адрес 0x50), WP — на GND (разрешить запись).

## Вход по паролю

При старте показывается экран блокировки. Пароль задаётся в
[`app_config.h`](app_config.h):

```c
#define APP_PASSWORD   "1234"
```

Клавиатура на экране входа — цифровая, поэтому **пароль должен состоять из цифр**.
Кнопка **Lock** в шапке главного экрана возвращает на экран блокировки.

> Это простая защита от случайного доступа, а не криптографическая.

## Сборка (Arduino IDE)

1. **Ядро:** установить *esp32* от Espressif (**Arduino-ESP32 v3.x**) через
   Boards Manager.
2. **Плата:** `ESP32S3 Dev Module`, настройки:
   - PSRAM: **OPI PSRAM** (обязательно — буферы LVGL в PSRAM);
   - Flash Size: 8MB или 16MB;
   - USB CDC On Boot: Enabled (для Serial-лога).
3. **Библиотека:** `lvgl` **8.3.x** через Library Manager.
4. **lv_conf.h:** скопировать `lv_conf_template.h` из библиотеки LVGL рядом с
   папкой `lvgl` и переименовать в `lv_conf.h`, затем задать:
   ```c
   #define LV_CONF_INCLUDE_SIMPLE 1
   #define LV_COLOR_DEPTH   16
   #define LV_COLOR_16_SWAP 0      // если цвета инвертированы — поставить 1
   #define LV_USE_TABVIEW   1
   #define LV_USE_KEYBOARD  1
   #define LV_MEM_SIZE      (64 * 1024)
   ```
   Свои шрифты (`ui_font_18/24/34`) уже в проекте — встроенные montserrat не нужны.
5. Открыть `esp32-s3-eeprom-programmer.ino` (все файлы папки собираются вместе),
   выбрать порт и прошить.

## Карта выводов платы (для справки)

RGB LCD: `DE=5, VSYNC=3, HSYNC=46, PCLK=7`;
данные `B3..B7 = 14,38,18,17,10`, `G2..G7 = 39,0,45,48,47,21`,
`R3..R7 = 1,2,42,41,40`; такты 16 МГц, HSYNC 8/4/8, VSYNC 16/4/16.
I²C: `SDA=8, SCL=9`. Тач INT `GPIO4`. Сбросы/подсветка — через CH422G
(`WR_SET=0x24`, `WR_IO=0x38`).

## Примечания

- Логика программаторов проверена на ПК (побайтовое совпадение с Python).
- Инициализация дисплея/тача выполнена по официальной карте выводов Waveshare.
  На реальном железе автор код не прошивал — при первом запуске проверьте
  Serial-лог и, при инверсии цветов, переключите `LV_COLOR_16_SWAP`.
- Тексты интерфейса — латиницей (стандартные шрифты LVGL без кириллицы).
