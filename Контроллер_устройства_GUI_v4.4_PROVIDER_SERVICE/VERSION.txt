Контроллер устройства 4.4 PROVIDER SERVICE
Дата сборки: 2026-07-26

Назначение: работа только с реальным устройством через Serial/оптопорт,
TCP-шлюз и GSM/SMS. Виртуального прибора и подмены ответов нет.

Новое в 4.4:
- штатная Provider-авторизация: PASSWORD_PROVIDER=…;
- подтверждение уровня чтением provider-only команды PASWORD_PROVID_VALUE;
- подтверждённая сессия действует 15 минут и сбрасывается при отключении;
- Volume/VOLUME_GLOB/VOLUME_COMMIS/VOLUME_DISC записываются отдельно:
  Provider auth -> SET один раз -> обязательный read-back;
- CLEAR_ARHIVE больше не запускается автоматически после записи показаний;
- очистка архива вынесена в отдельную подтверждаемую операцию;
- для обеих сервисных операций обязательны оператор и служебная причина;
- пароль и проверочное значение скрываются из JSONL/CSV и сырого HEX-журнала;
- Provider-запись по SMS заблокирована как несинхронная и неподтверждаемая;
- CLI: --set-reading / --clear-archive, --provider-password или SMT_PROVIDER_PASSWORD.

Важно: программа использует только явно введённые штатные учётные данные,
не подбирает пароль и не обходит права прошивки. Реальную поддержку команд
определяет конкретная версия ПО прибора.

Контроль качества:
- синтаксическая проверка всех Python-модулей;
- 20 автоматических тестов;
- GUI smoke-test;
- фактические команды конкретному прибору без оборудования не отправлялись.
