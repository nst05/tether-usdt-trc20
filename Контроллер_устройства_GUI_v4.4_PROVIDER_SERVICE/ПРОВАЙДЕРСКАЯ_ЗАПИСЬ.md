# Штатная Provider-запись показаний

## Назначение

Модуль предназначен для авторизованной сервисной работы с выделенным прибором.
Он не подбирает пароль и не обходит защиту прошивки.

## Авторизация

1. Подключиться по оптопорту/Serial или синхронному TCP-шлюзу.
2. Выбрать `PASSWORD_PROVIDER`.
3. Ввести действующий пароль и нажать «Аутентифицировать».
4. Программа отправит пароль и затем прочитает `PASWORD_PROVID_VALUE`.
5. Только после допустимого ответа появится статус «Provider подтверждён».

Сессия действует 15 минут и сбрасывается при отключении. По GSM/SMS автоматическая
проверка отключена: `+CMGS/OK` подтверждает только приём SMS локальным модемом.

## Запись показания

Для `Volume`, `VOLUME_GLOB`, `VOLUME_COMMIS`, `VOLUME_DISC`:

1. включить экспертный режим;
2. подтвердить Provider;
3. указать новое значение;
4. указать оператора и служебную причину;
5. ввести `ЗАПИСАТЬ`;
6. программа прочитает старое значение и `ArcNumRecords`;
7. отправит SET ровно один раз;
8. повторно прочитает параметр и сравнит значение.

`CLEAR_ARHIVE` при этом не отправляется. Технический журнал сохраняет оператора,
причину, старое и подтверждённое новое значение; пароль не сохраняется.

## Отдельная очистка архива

Кнопка «Очистить измерительный архив отдельно» отправляет `CLEAR_ARHIVE` только
после отдельного подтверждения `ОЧИСТИТЬ`. Успех фиксируется лишь после чтения
`ArcNumRecords=0`.

## CLI

Windows CMD:

```bat
set SMT_PROVIDER_PASSWORD=пароль
python smt_cli.py serial COM3 --set-reading 1234.5678 --confirm-write --expert ^
  --operator engineer-1 --reason "поверка"

python smt_cli.py serial COM3 --clear-archive --confirm-clear-archive --expert ^
  --operator engineer-1 --reason "регламент"
```

Linux/macOS:

```bash
export SMT_PROVIDER_PASSWORD='пароль'
python3 smt_cli.py serial /dev/ttyUSB0 --set-reading 1234.5678 \
  --confirm-write --expert --operator engineer-1 --reason 'поверка'
```
