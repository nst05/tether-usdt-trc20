📊 ПОЛЕ 2 (HEX) — Как подстраивается

Шаги:
  1. Берём значение из Поля 1:        9442.36
  2. Парсим как float                 float("9442.36")
  3. Умножаем на SCALE (100):         9442.36 × 100 = 944236
  4. Округляем до целого:             944236
  5. Проверяем диапазон:              0 ≤ 944236 ≤ 4294967295 ✓
  6. Кодируем в 4 байта BIG-ENDIAN:   944236 → 00 0E 68 6C
  7. Выводим в hex:                   0x000E686C

Код:
  raw = int(round(value * SCALE))
  hex_bytes = raw.to_bytes(4, "big", signed=False)
  self.i2c_hex_display.setText(f"0x{hex_bytes.hex().upper()}")

🔐 ПОЛЕ 3 (CRC-16) — Как подстраивается

Шаги:
  1. Берём HEX из Поля 2:             00 0E 68 6C (4 байта)
  2. Создаём 40-байтовый блок:
     • Байты 0-3:    00 0E 68 6C
     • Байты 4-7:    00 0E 68 6C  (дубль)
     • Байты 8-39:   00 00 ... 00 (паддинг, 32 байта)
  3. Вычисляем CRC-16 CCITT:
     • Полином:      0x1021
     • Init:         0xFFFF
     • No reflection
     • XOR out:      0x0000
  4. Результат:                       0xAC55
  5. Выводим:                         0xAC55

Код:
  block = hex_bytes + hex_bytes + b'\x00' * 32
  crc = crc16_ccitt(block)
  self.i2c_crc_display.setText(f"0x{crc:04X}")

✅ ВАЖНОЕ: ЧТО ПОКАЗЫВАЮТ ПОЛЯ 2 И 3

Поля 2 и 3 показывают РОВНО ТО, ЧТО БУДЕТ ЗАПИСАНО В EEPROM!

  Пользователь видит:                  Что будет записано:
  
  Значение: 9442.36                    Блок 42 байта:
  HEX:      0x000E686C                 00 0E 68 6C  ← Значение
  CRC-16:   0xAC55                     00 0E 68 6C  ← Дубль
                                       00 00 ... 00 ← Паддинг
                                       AC 55        ← CRC

════════════════════════════════════════════════════════════════════════════════

📋 АЛГОРИТМ В ЦЕЛОМ

  1. Поле 1 (Значение) — пользователь вводит число
  2. textChanged() срабатывает
  3. on_i2c_value_changed() вызывается
  4. Вычисляются:
     - Поле 2 = encode_value(field1)
     - Поле 3 = crc16_ccitt(40-byte-block)
  5. Результаты выводятся на экран
  6. Пользователь видит что будет записано ДО нажатия кнопки
