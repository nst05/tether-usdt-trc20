# veho — сервис доставки

Веб-приложение для управления курьерской доставкой, построенное на Flask.
Учёт отправлений, курьеров и клиентов, отслеживание посылок по трек-номеру и
публичная страница трекинга.

## Возможности

- **Панель управления** — статистика по отправлениям, статусам и выручке.
- **Отправления** — создание, редактирование, поиск и фильтрация; трек-номера
  формата `VEH-ГОД-XXXXXX`; наложенный платёж, габариты, вес, тип услуги.
- **Статусы доставки** — поток `Создано → Забрано → В пути → На доставке →
  Доставлено`, плюс `Возврат` / `Отменено`. Продвижение статуса одной кнопкой
  с записью в историю (с указанием локации).
- **Курьеры** — карточки с транспортом, зоной обслуживания и статистикой.
- **Клиенты** — частные лица и бизнес-отправители.
- **Публичное отслеживание** — страница `/track` и JSON API
  `/api/shipments/<трек-номер>`.

## Технологии

Flask, Flask-SQLAlchemy (SQLite), Flask-WTF, Bootstrap 5.

## Запуск

```bash
cd veho
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python seed.py     # (необязательно) наполнить демо-данными
python run.py
```

Приложение будет доступно на http://localhost:5000
(порт можно задать переменной окружения `PORT`).

## Структура

```
veho/
├── app.py          # фабрика приложения и маршруты
├── models.py       # модели: Client, Courier, Shipment, ShipmentEvent
├── forms.py        # формы WTForms
├── run.py          # точка входа
├── seed.py         # демо-данные
├── requirements.txt
└── templates/      # шаблоны Jinja2 (base, dashboard, shipments, couriers, clients, track)
```

## API

`GET /api/shipments/<tracking_number>` — статус и история отправления в JSON:

```json
{
  "tracking_number": "VEH-2026-100001",
  "status": "in_transit",
  "status_label": "В пути",
  "progress": 50,
  "events": [ { "status": "picked_up", "location": "...", "timestamp": "..." } ]
}
```
