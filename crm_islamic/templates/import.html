    Импорт из Excel

    Загрузите данные из Excel в три шага: клиенты → договоры → платежи

    ①
    Клиенты
    Скачайте шаблон, заполните данные клиентов, загрузите.
    ②
    Договоры
    Скачайте шаблон договоров. Телефон клиента связывает договор с клиентом из шага 1.
    ③
    История платежей
    Платежи за прошедшие месяцы — с любыми датами. Просроченные определятся автоматически.
    Просрочки: если у клиента были неоплаченные платежи — создайте договор с правильной датой начала, внесите только фактически полученные платежи (с реальными датами). Остальные строки графика автоматически получат статус «Просрочен».
    ① Импорт клиентов

    Обязательные поля: Фамилия, Имя, Телефон.
    Дубликаты по телефону пропускаются.

    Скачать шаблон клиентов (.xlsx)
    ② Импорт договоров

    Обязательные поля: Телефон клиента, Себестоимость, Срок.
    Договоры с прошедшими датами — допустимы. График создаётся автоматически.

    Скачать шаблон договоров (.xlsx)
    ③ Импорт истории платежей

    Обязательные поля: Номер договора, Дата платежа, Сумма.
    Любые прошедшие даты. Строки графика закрываются по порядку.

    Скачать шаблон платежей (.xlsx)
    Советы по заполнению
    Даты: формат ДД.ММ.ГГГГ
    Пример: 15.03.2024
    Пол: М или Ж
    Занятость: employed / self_employed / business_owner / unemployed
    Способ оплаты: cash / bank_transfer / card / online
    Русское тоже принимается: наличные, карта
