# Прямая Provider-запись

Версия v4.5 реализует ровно штатную последовательность:

1. Подключиться к прибору через Serial/оптопорт или TCP-шлюз.
2. Включить экспертный режим.
3. Передать действующий `PASSWORD_PROVIDER`.
4. Для синхронного канала программа проверяет уровень чтением `PASWORD_PROVID_VALUE`.
5. Выбрать `Volume`, `VOLUME_GLOB`, `VOLUME_COMMIS` или `VOLUME_DISC` и отправить прямой `SET`.
6. При необходимости оставить включённым флажок read-back.

Программа не требует имени оператора, причины, 15-минутной сессии или обязательного изменения архива.
`CLEAR_ARHIVE` — отдельная критическая команда. Она не отправляется автоматически и не блокируется специальным сценарием.

## CLI

Прямая запись с проверкой:

```bash
python smt_cli.py serial COM3 --set-reading 1234.5678 --provider-password YOUR_PASSWORD --expert
```

Без read-back:

```bash
python smt_cli.py serial COM3 --set-reading 1234.5678 --provider-password YOUR_PASSWORD --expert --no-readback
```

Любая низкоуровневая команда после Provider-авторизации:

```bash
python smt_cli.py serial COM3 --send "VOLUME_GLOB=1234.5678" --provider-password YOUR_PASSWORD --expert
python smt_cli.py serial COM3 --send CLEAR_ARHIVE --provider-password YOUR_PASSWORD --expert
```

По SMS программа может отправить пароль и команду, но `+CMGS/OK` подтверждает только отправку модемом. Выполнение прибором проверяется отдельным входящим SMS.
