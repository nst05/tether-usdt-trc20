# Привязка программы к компьютеру

CRM «Исламская рассрочка» работает только на том компьютере, для которого
выпущен ключ активации. Интернет для проверки не нужен — всё офлайн.

## Как это выглядит для клиента

1. Клиент запускает программу и открывает `http://localhost:5000`.
2. Пока копия не активирована, любая страница перебрасывает на **/activate**.
3. На странице активации показан **код компьютера**, например
   `B15C0-434B2-B000A-6E8A7`. Кнопка «Скопировать код» кладёт его в буфер.
   Тот же код печатается в консоли при запуске.
4. Клиент присылает код вам, получает ключ вида
   `AEEYW4A-SOU4GA3-GBLV664`, вставляет его в поле и нажимает «Активировать».
5. Ключ сохраняется в файл `license.key` рядом с базой данных
   (в папке с `.exe`). Больше вводить его не нужно.

Текущее состояние лицензии — в меню **Система → Лицензия**: тип, срок,
код компьютера, кнопка удаления лицензии при переносе на другой ПК.

## Как выпустить ключ (для продавца)

`keygen.py` — ваш инструмент, клиенту его передавать нельзя.

```bash
# бессрочный ключ
python keygen.py B15C0-434B2-B000A-6E8A7

# ключ на год
python keygen.py B15C0-434B2-B000A-6E8A7 --days 365

# код текущего компьютера
python keygen.py --my-code

# проверить выпущенный ключ
python keygen.py --check AEEYW4A-SOU4GA3-GBLV664 --code B15C0-434B2-B000A-6E8A7
```

`--days` отсчитывается от **дня выпуска ключа**, а не от дня активации.
Для продления просто выпустите новый ключ и попросите ввести его на
странице «Лицензия → Ввести ключ активации».

## ОБЯЗАТЕЛЬНО перед продажей: смените секрет

Ключи подписываются HMAC-SHA256 с общим секретом. Секрет по умолчанию
лежит в открытом виде в `crm_islamic/licensing.py`:

```python
DEFAULT_SECRET = 'islamic-crm-license-secret-change-me-2024'
```

Замените эту строку на свою (длинную, случайную) **до сборки .exe**.
Тот же секрет нужен генератору ключей — либо он берётся из файла, либо
задайте переменную окружения при запуске keygen:

```bash
CRM_LICENSE_SECRET='ваш-секрет' python keygen.py B15C0-434B2-B000A-6E8A7
```

Если секрет в сборке и в генераторе не совпадут — ключи не подойдут.

## Что именно считается «компьютером»

Берётся первый доступный идентификатор по приоритету:

| ОС      | Источник                                            | Метка       |
|---------|-----------------------------------------------------|-------------|
| Windows | `HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid`   | `win-guid`  |
| Windows | серийный номер системного тома                       | `win-vol`   |
| macOS   | `IOPlatformUUID`                                     | `mac-uuid`  |
| Linux   | `/etc/machine-id`                                    | `linux-id`  |
| Linux   | `/sys/class/dmi/id/product_uuid`                     | `linux-dmi` |
| любая   | MAC-адрес                                            | `mac`       |

Значение хешируется SHA-256, первые 20 hex-символов и есть код компьютера.
Используемый источник виден на странице «Лицензия».

Код **не меняется** при замене дисков, ОЗУ, видеокарты или переустановке
программы. Код **изменится** при переустановке Windows (новый MachineGuid)
или переносе на другой ПК — тогда нужен новый ключ.

## Защита от обхода

* Ключ проверяется при каждом запросе, а не только при активации.
* Скопированный на другой ПК `license.key` не работает — подпись
  привязана к коду компьютера.
* Дата последнего запуска пишется в `license.key` с контрольной суммой:
  перевод системных часов назад больше чем на 2 дня блокирует программу.
* Проверку можно отключить **только** при запуске из исходников
  (`CRM_LICENSE_DISABLE=1`) — в собранном `.exe` эта переменная игнорируется.

Честное предупреждение: секрет зашит в исполняемый файл, поэтому защита
рассчитана на обычного пользователя, а не на реверс-инжиниринг. Если
нужна стойкость к вскрытию — надо переходить на подпись Ed25519
(приватный ключ остаётся у вас, в программе только публичный) и
обфускацию сборки.

## Файлы

| `crm_islamic/licensing.py`                    | отпечаток ПК, ключи, проверка, роуты |
