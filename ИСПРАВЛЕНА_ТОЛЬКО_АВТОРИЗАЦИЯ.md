# v4.5.1 — исправлена только авторизация

Основа сборки — v4.5 PROVIDER DIRECT. Остальные возможности и ограничения не менялись.

Изменено только следующее:

- после `PASSWORD_PROVIDER=<6 символов>` программа больше не читает `PASWORD_PROVID_VALUE`;
- Provider считается принятым, если ответ самой команды не содержит явного отказа;
- `PASSWORD_OMEGA=<значение>` обрабатывается аналогично для Omega;
- по SMS статус остаётся неподтверждённым, потому что ответ модема подтверждает отправку SMS, а не смену уровня прибором;
- `PASSWORD_FABRIC`, `MAGIC`, `ENABLE_OMEGA` и `PASSWORD_OMEGA2` по-прежнему только отправляются: программа не выдумывает для них подтверждение уровня.

Не изменялись каталог команд, автоматический аудит, чтение параметров, права F1/F2, терминал, сценарии, телеметрия, история и логика записи показаний.
