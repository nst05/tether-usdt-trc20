# Модель доступа Provider / Omega

## Что подтверждено прошивкой

Текущий уровень хранится в байте `0x20000D62`:

- `0x66` (`f`) — Provider, права F1;
- `0x55` (`U`) — Omega, права F2;
- другое значение — подтверждённый уровень отсутствует.

Отдельной колонки Factory в записи команды нет. Поэтому `f` нельзя подписывать как Factory: в проверках обработчиков это Provider/F1.

## Provider

Обработчик `PASSWORD_PROVIDER` проверяет длину шесть символов, сравнивает введённое значение с сохранённым паролем и возвращает ответ успеха либо отказа. Версия 4.6:

1. проверяет длину;
2. отправляет `PASSWORD_PROVIDER=<значение>` один раз;
3. не читает `PASWORD_PROVID_VALUE`;
4. считает уровень активным только при непустом ответе без признаков отказа;
5. сбрасывает локальный уровень при отключении.

`PASWORD_PROVID_VALUE` остаётся обычным служебным параметром каталога.

## Omega

Для Omega отправляется `PASSWORD_OMEGA=<значение>`. Исследованные материалы также содержат `PASSWORD_OMEGA2`, `ENABLE_OMEGA` и `MAGIC`, но точная обязательная последовательность зависит от сборки прошивки. Программа не объединяет их автоматически и не придумывает скрытый алгоритм.

## Применение F1/F2

После принятого пароля операция из каталога проверяется локально:

- чтение: `0100` или `0101`;
- запись/действие: только `0101`.

Затем та же команда уходит прибору, который выполняет собственную проверку. Локальная матрица не является обходом или заменой контроля прошивки.

## Низкоуровневый терминал

Свободная команда и RAW HEX оставлены для инженерной диагностики. Они не меняют локальный статус доступа и не гарантируют выполнение. Для критических операций требуется экспертный режим, а окончательный ответ даёт прибор.

## PASSWORD_FABRIC

Команда сохранена в полном каталоге, потому что она присутствует в таблице прошивки. Однако отдельный Factory-уровень не подтверждён ни F1/F2, ни значениями байта текущего доступа. Поэтому программа не показывает кнопку входа Factory и не использует `PASSWORD_FABRIC` для изменения локального уровня.
