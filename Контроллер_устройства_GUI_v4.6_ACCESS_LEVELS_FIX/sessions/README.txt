В эту папку программа автоматически сохраняет данные реальной работы:

- optic_*.jsonl / optic_*.log — фактические TX/RX-обмены с прибором;
- session_*.log / session_*.json — принятые пакеты телеметрии;
- telemetry.sqlite3 — накопительная база телеметрии и аномалий.

Локальный журнал корректировок показаний не создаётся. Операция записи показаний
может выполнить штатную команду CLEAR_ARHIVE; это не удаляет локальные файлы
сессий и базу telemetry.sqlite3. Секретные значения в журнале обменов маскируются.
Перед передачей чистого проекта рабочие журналы можно удалить, оставив README.txt.
