# Контроллер устройства 4.6 ACCESS LEVELS FIX

Программа работает с реальным прибором через USB-оптопорт/Serial, TCP-шлюз или GSM/SMS. Каталог содержит 158 команд прошивки. В версии 4.6 исправлена модель доступа по результатам анализа прошивки.

## Исправленная модель доступа

В таблице диспетчеризации есть два уровня прав:

- **Provider / F1** — внутренний байт доступа `0x66` (`'f'`);
- **Omega / F2** — внутренний байт доступа `0x55` (`'U'`).

Отдельный уровень **Factory** таблицами F1/F2 не подтверждён, поэтому он удалён из выбора уровня. Команда `PASSWORD_FABRIC` остаётся в полном каталоге как служебная команда с историческим именем, но GUI не объявляет её отдельной авторизацией.

### Provider

Прошивка ожидает:

```text
PASSWORD_PROVIDER=<6 символов>
```

При успешном сравнении прошивка открывает уровень Provider. Программа определяет успех по ответу самой команды `PASSWORD_PROVIDER`. Дополнительный запрос `PASWORD_PROVID_VALUE` больше не используется: это служебный параметр, а не достоверный индикатор активной сессии.

### Omega

Программа отправляет введённое оператором значение:

```text
PASSWORD_OMEGA=<значение>
```

Формат и дополнительная сервисная логика Omega могут отличаться между версиями прошивки. `PASSWORD_OMEGA2`, `ENABLE_OMEGA` и `MAGIC` остаются отдельными командами каталога и не выполняются автоматически.

### Проверка команд

После принятия пароля GUI включает соответствующую колонку прав:

- `0101` — чтение и запись/действие;
- `0100` — только чтение;
- `0000` — нет доступа.

Кнопка `SET` или `Действие` активируется только при разрешении текущего F1/F2. Прошивка повторно проверяет уровень при каждой команде и может отклонить её независимо от состояния GUI.

Свободный терминал и RAW HEX являются низкоуровневыми инструментами и не подменяют права прибора. Критические команды дополнительно требуют экспертного режима.

## Права команд показаний

По извлечённой таблице этой прошивки:

| Команда | Provider/F1 | Omega/F2 | Запись из каталога |
|---|---:|---:|---|
| `Volume` | `0000` | `0100` | нет, только чтение Omega |
| `VOLUME_GLOB` | `0101` | `0000` | Provider |
| `VOLUME_COMMIS` | `0100` | `0000` | нет, Provider только читает |
| `VOLUME_DISC` | `0101` | `0101` | Provider или Omega |

Для разрешённой записи отправляется один `NAME=value`. Для показаний можно включить необязательный read-back. `CLEAR_ARHIVE` является отдельной командой и автоматически после записи не вызывается.

## Реальные каналы связи

### USB-оптопорт / Serial

Поддерживаются выбор COM/tty-порта, скорость, биты, чётность, стоп-биты, DTR/RTS, аппаратное/программное управление потоком, таймауты, кадрирование `cr`, `crlf`, `brace`, `iec` и автоопределение по `DevInfo`. Оптическое эхо удаляется только из разбираемого ответа; исходные TX/RX сохраняются в журнале.

### TCP-шлюз

Командный request/response через реальный TCP-шлюз с настройкой host, port, таймаута и терминатора.

### GSM/SMS

Поддерживаются AT-проверка модема, отправка команды SMS, чтение непрочитанных SMS и удаление сообщений. Ответ `+CMGS/OK` подтверждает только принятие SMS модемом. Поэтому пароль, отправленный по SMS, не переводит локальный GUI в подтверждённый Provider/Omega до получения и разбора ответа прибора.

## Остальные возможности

- полный каталог 158 команд;
- паспорт и безопасный READ-аудит;
- RAW HEX и AT-консоль;
- пакетные сценарии и мониторинг;
- TCP-приём телеметрии, SQLite, дедупликация и экспорт;
- разбор чекпоинта, измерительного архива и событий из flash-дампа;
- журнал реальных сеансов JSONL/CSV с маскированием секретов.

Автоматическая диагностика доступа не читает `PASSWORD_*`, потому что исследованная прошивка может вернуть сохранённый пароль открытым текстом.

## Запуск

### Windows

```bat
py -3 -m pip install -r requirements.txt
start_gui.bat
```

### Linux

```bash
python3 -m pip install -r requirements.txt
./start_gui.sh
```

## CLI

```bash
# Чтение
python smt_cli.py serial COM3 --get DevInfo

# Provider-аутентификация и разрешённая F1-запись VOLUME_GLOB
set SMT_ACCESS_PASSWORD=123456
python smt_cli.py serial COM3 --set-reading 1234.5678 \
  --reading-command VOLUME_GLOB --auth-level provider --expert

# Разрешённая обоим уровням запись VOLUME_DISC
python smt_cli.py serial COM3 --set-reading 1.25 \
  --reading-command VOLUME_DISC --auth-level omega \
  --access-password OMEGA_VALUE --expert

# Произвольная команда после предъявления Provider-пароля
python smt_cli.py serial COM3 --send CLEAR_ARHIVE \
  --auth-level provider --access-password 123456 --expert

# GSM-модем
python smt_cli.py sms COM7 +79990000000 --at AT+CSQ
python smt_cli.py sms COM7 +79990000000 --send DevInfo
python smt_cli.py sms COM7 +79990000000 --inbox
```

Пароли в примерах являются только форматом запуска. Используется действующее значение конкретного авторизованного прибора; программа ничего не подбирает.
