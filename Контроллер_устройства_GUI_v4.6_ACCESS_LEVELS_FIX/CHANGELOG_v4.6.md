# Изменения v4.6

- Удалён выдуманный уровень Factory из селектора доступа.
- Исправлено соответствие байтов: `f` — Provider/F1, `U` — Omega/F2.
- Удалена ложная проверка Provider через `PASWORD_PROVID_VALUE`.
- Добавлена штатная подача пароля Omega через `PASSWORD_OMEGA`.
- Provider-пароль проверяется на длину ровно 6 символов.
- Активный уровень определяется ответом самой команды `PASSWORD_*` и сбрасывается при отключении.
- Кнопки SET/действий зависят от F1/F2 выбранной команды.
- Та же матрица применяется к пакетным сценариям и CLI с `--auth-level`.
- Удалена специальная «Provider-запись всех показаний»: права теперь берутся из каталога.
- Автоматические сканы больше не читают `PASSWORD_*` и другие секреты.
- Обновлены описания `PASSWORD_FABRIC`, `PASSWORD_OMEGA2`, `ENABLE_OMEGA`, `MAGIC`.
